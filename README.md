# Sunnyfolk for Roblox

A Roblox version of [Sunnyfolk](https://github.com/lschandler81/game), a cosy little animal town
for children aged 6–9. Make friends, collect coins and find a hat you love.

## What's here so far

- `assets/characters/`: the Sunnyfolk animals (capybara, bunny, guinea pig, duck, penguin, frog),
  every hat and piece of clothing, and the residents. They're exported from the web game as 3D
  models ready to import into Roblox Studio. `docs/characters.md` explains what's in them,
  how to import them and how to make them move.

The game itself (Luau code synced into Roblox Studio with [Rojo](https://rojo.space)) comes next.
